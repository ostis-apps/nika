# Агент добавления события в гугл календарь

Данный агент создает событие в календаре на основе характеристик, полученных от классификатора.

**Класс действий:**

`action_add_google_calendar_event`

**Параметры:**

1. Узел сообщения;
2. Узел авторизованного пользователя.

Логическое правило, активирующее агента изображено ниже.

![Параметры сообщения](./images/lr_add_event_message.png)

Обязательные параметры события в сообщении:

- название;
- время начала(в utc формате).

Дополнительно можно указать время окончания(в utc формате). Если не указать время окончания, то оно будет установлено на час позже стартового времени.

**Ход работы агента:**

- Агент ищет все параметры события.
- Агент находит токен доступа автора сообщения.
- Агент отправляет запрос в Google Calendar API на создание события с найденными параметрами при помощи токена доступа.
- Агент завершает работу.

## Пример

Пример входной структуры:

![Входная структура](./images/add_event_start.png)

Если агент отработает успешно, тогда в календаре автора появится событие с заявленными характеристиками.

## Результат

Возможные результаты:

- `SC_RESULT_OK` - событие создано;
- `SC_RESULT_ERROR`- внутренняя ошибка.
