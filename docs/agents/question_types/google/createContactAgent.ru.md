# Агент создания контакта

Данный агент генерирует в базе знаний узел контакта, привязанный к автору сообщения. У контакта есть имя и адрес электронной почты.

**Класс действий:**

`action_create_contact`

**Параметры:**

1. Узел сообщения;
2. Узел авторизованного пользователя.

Логическое правило, активирующее агента изображено ниже.

![Параметры сообщения](./images/create_contact.png)

**Ход работы агента:**

* Агент находит все параметры контакта в сообщении.
* Агент привязывает к узлу автора сгенерированный узел контакта.
* Агент завершает работу.

## Пример

Пример входной структуры:

![Входная структура](./images/create_contact_start.png)

В результате к автору привяжется узел контакта.

## Результат

Возможные результаты:

* `SC_RESULT_OK` - контакт сгенерирован;
* `SC_RESULT_ERROR`- внутренняя ошибка.
