# Агент создания токенов доступа

Данный агент генерирует в базе знаний токены доступа и привязывает их к узлу автора.

**Класс действий:**

`action_create_google_tokens`

**Параметры:**

1. Узел автора;
2. Код, полученный из OAuth2.0 сервиса.

**Ход работы агента:**

* Агент при помощи кода отправляет запрос на OAuth2.0 сервис для получения токенов доступа.
* После получения токенов они шифруются и привязываются к узлу автора.
* Агент завершает работу.

## Результат

Возможные результаты:

* `SC_RESULT_OK` - токены сгенерированы;
* `SC_RESULT_ERROR`- внутренняя ошибка.
